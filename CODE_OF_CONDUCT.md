# Code of conduct

Everyone is welcome to read, use, discuss and suggest. In issues,
discussions and pull requests:

- Be respectful. Critique ideas and code, never people.
- Stay on topic and assume good faith.
- No harassment, threats, doxxing, spam, scams or impersonation.
- Never ask anyone for keys, seed phrases, passwords or money. The project
  will never ask you for them either.

The maintainer moderates and may hide or delete content, lock threads, or
block accounts that break these rules. Report a problem privately through
the repository's *Report a vulnerability* form or to the maintainer's
GitHub profile.
