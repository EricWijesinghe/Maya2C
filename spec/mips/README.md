# Maya2C Improvement Proposals

A change to any rule in `spec/` is a MIP: a numbered file here, copied from
[0000-template.md](0000-template.md). A MIP is *Draft* until its vectors
exist and pass against the reference and the node, *Accepted* when governance
schedules an activation height, *Final* once that height has passed.

A MIP never edits a rule in place. It adds new rule IDs and marks the old
ones superseded from the activation height, because both must stay
checkable: a node syncing from genesis still applies the old rule below it.
