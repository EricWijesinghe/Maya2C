# Next evolution brief (Eric, 2026-10-30)

Saved as a **future to-do, after mainnet**. It is a brief, not a plan. Before
any code it goes through the usual gate:
- each item is reconciled against `features.toml`, `docs/architecture-vision.md`
  and ADR-016;
- what already exists is marked as existing;
- what collides with a numbered invariant is reported, not built around;
- the remainder gets ADRs.

Numbers and superlatives below are Eric's targets, not claims (Standing
Orders 2 and 10).

---
