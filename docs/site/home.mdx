<h2 id="code-title" class="home-h2">Read the chain in a few lines</h2>
<p class="home-lede">Each snippet talks to a chain on your own machine: the <a href="/guides/quickstart/">local devnet</a> serves JSON-RPC on 127.0.0.1:8545, and the gateway in front of it listens on 127.0.0.1:8080.
```rust title="sdks/rust · from source"
use maya2c_sdk::Client;

let url = "http://127.0.0.1:8080";
let client = Client::new(url)?;
// A spec test vector address:
let addr = "maya1qq657tlpk6cucz6mh4x4kvx2hthu90an4qw5wx0g9y44pynj86lxsgd736f";
let bal = client.balance(addr)?;
println!("{} units", bal.balance);
```

<TabItem label="Python">

```python title="sdks/python · from source"
from getpass import getpass
from maya2c_sdk import Client, Wallet

url = "http://127.0.0.1:8545"
client = Client(url)
wallet = Wallet("l1-wallet",
    "wallet.key", getpass(), client)
to = "maya1qq657tlpk6cucz6mh4x4kvx2hthu90an4qw5wx0g9y44pynj86lxsgd736f"
txid = wallet.transfer(to, 1_000)
```
