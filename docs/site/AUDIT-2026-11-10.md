# Site UI audit, 2026-11-10

Scope: the public site in `docs/site` (Astro 7 + Starlight 0.42), every
top-level page reachable from the header and the homepage. Branch
`feat/site-ui-upgrade`, base `d975d326`.

How it was checked, so each finding can be re-run:

- Screenshots: headless Chrome over the DevTools protocol (no npm package),
  full page, 1440 px dark and 360 px light, both with `prefers-reduced-motion:
  reduce` so scroll-reveal animations do not leave blank sections in a
  full-page capture. "Before" is the live <https://maya2c.dev> on 2026-11-10;
  "after" is this branch's `dist/` served locally. Files in
  `reports/site/2026-11-10-ui-upgrade/`.
- Contrast: WCAG 2.x relative-luminance formula on the token pairs in
  `src/styles/maya.css` (script in the PR description).
- Weight: byte counts of `dist/` after `npm run build` (section "Measured").
- Text: `rg` over `home.mdx`, `authored/`, `src/components`, `src/pages`.

No Lighthouse run: Lighthouse is not installed on this machine, so no
Lighthouse score or LCP figure appears anywhere here.

## Findings, ranked

Status: **fixed** in this PR, **open** (with the reason it is not in this PR).

### High

1. **Primary buttons fail WCAG AA contrast.** The hero's primary button was
   white on the teal gradient `#1fb5c2 → #2fb9c3`: 2.49:1 and 2.37:1 (needs
   4.5:1 at 15 px). In light mode the shared `--accent-fill` started at
   `#12a3b0`, 3.05:1 under white text, and it also fills the header's current
   page pill. **Fixed**: the hero uses `--accent-fill` / `--on-accent`
   (dark: `#02161a` on `#22c3cf → #0e8f9c`, 8.63 to 4.79:1); light
   `--accent-fill` is now `#0b7d89 → #0b7280` (4.87 to 5.63:1 under white).
2. **Two different gate counts on one page.** The homepage showed "6 / 10
   gates" (MainnetDial and the progress orbs, from `mainnet-gates.ts`, which
   mirrors `docs/mainnet-v1-plan.md`) and, further down, "6 / 8 gates passed,
   75 %" (LaunchLadder + LaunchStatus, from the older `launch-gates.ts`). A
   reader cannot tell which is true. **Fixed**: the homepage keeps the ten
   mainnet gates (the plan is the authority) and no longer renders the
   eight-gate ladder. The two components remain in `src/components/` unused;
   deleting them or moving them to their own page is the owner's call.
3. **Hard-coded status on the homepage.** "Testnet paused: 7 days, zero
   halts" as a section title and "7 d 15 h, zero halts" on the Uptime orb were
   typed into `home.mdx`, so they stay true only until the next run
   (Standing Orders 1-2). **Fixed**: neutral title, and the Uptime orb links
   to `/health/`, which reads `public/health/incidents.json`.
4. **No navigation on the homepage at phone width.** The homepage uses
   Starlight's splash template, which has no sidebar, and the header's
   primary nav is hidden below 72 rem. At 360 px the only control in the
   header is search. **Partly fixed**: the hero now carries one button per
   audience (Try it, Build on it, Run a node), so each journey starts one tap
   away. **Open**: a compact nav row for phones on every page changes the
   header height Starlight lays out against; it needs its own change and a
   check of every template.

### Medium

5. **Text wall where a graphic fits.** "In plain words" was four paragraphs
   and a list of six links. **Fixed**: one sentence plus `TxJourney`, an
   interactive five-step explainer (sign, check, order, vote, final) with a
   "break one lock" toggle for the hybrid signature and a committee-size
   slider whose quorum comes from `math/quorum.ts` (already tested against
   ADR-039 for n = 1..1000). It is labelled "illustration, not live data",
   needs no JavaScript to read (an ordered list without it), never moves
   until Play is pressed (WCAG 2.2.2), and drops transitions under reduced
   motion. Also placed on `/guides/transactions/`.
6. **Orphan page.** `/learn/signatures-live/` (four-step signature
   walkthrough) was linked from nowhere. **Fixed**: linked from the
   signatures guide and from the explainer's Sign step.
7. **Unused component with stale, typed numbers.** `StatBand.astro` held
   "2,972 tests" (2026-09-28) and "148 subsystems" as literals, in off-brand
   purple. **Fixed**: rewritten as the homepage facts band. Every figure comes
   from `public/health.json` or `public/progress.json` through
   `src/data/facts.ts`. Each card names its source and links to it, and a
   value the build could not get reads "unknown". `src/data/facts.test.ts`
   pins this; it failed when the function was pointed at the wrong field.
8. **The test count is 45 days old, and its note says otherwise.**
   `scripts/gen-health.mjs` writes `tests.passed = 2793, as_of 2026-09-26`
   with the note "Replaced by a fresh count when this runs in CI", but no
   workflow writes it (`site.yml` has no such step). The facts band shows the
   as-of date beside the number, so nothing reads as today's. **Open**: either
   a CI step that writes a real count, or drop the note. That is a change to
   CI, not to the UI.
9. **Light-mode signal and gold fail AA for small text.** `--signal #b06d0f`
   on `--void` 3.94:1, `--gold #9a7330` 4.07:1 (used at 12-13 px: the
   "project-run" note in the hero, kickers). **Fixed**: `#96590a` (5.32:1,
   4.97:1 on `--deep`) and `#85622a` (5.25:1, 4.91:1).
10. **Header nav named places, not audiences.** Seven entries; "Docs",
    "Testnet" and "Validators" led to overlapping journeys. **Fixed**:
    Experience, Build, Run a node, Explorer, Status, Built by Eric. "Run a
    node" lights on help-run, testnet, validators and mining pages; "Build" on
    quickstart, API, wallet and contracts.
11. **New-tab links not announced.** Header links that open a new tab showed
    only an `aria-hidden` arrow. **Fixed**: each carries a visually hidden
    "(opens in a new tab)".
12. **Hero says "reconnecting…" forever when the network is down.** Today the
    explorer, RPC and status endpoints answer Cloudflare error 1033 (tunnel
    down; checked with `curl`, 2026-11-10), so the chip never left
    "connecting / reconnecting". **Fixed**: if the stream never opened during
    the visit the chip says "offline"; "reconnecting" is kept for a stream
    that was live and dropped.
13. **Homepage length.** 10,011 px tall at 1440 px and 15,846 px at 360 px
    before this change, with the gate story told three times (dial, orbs,
    ladder). Removing the ladder and the text wall shortens it (figures in
    "Measured"). **Open**: progress orbs and the dial still overlap; merging
    them is a content decision.

### Low

14. **Nested `<label>` in `QuorumOverlap.astro`** (consensus guide): invalid
    HTML, and some screen readers announce the checkbox twice. **Fixed**.
15. **Structured data says the node runs on "Linux, Windows"** with a comment
    that macOS waits for a Mac build, but `node-v0.1.0-testnet.4` ships
    `maya2c-aarch64-apple-darwin` and `maya2c-x86_64-apple-darwin`
    (`gh release view`). **Open**: the fix is in `astro.config.mjs`, which a
    parallel branch (`fix/site-csp-help-run`) is editing; left to avoid a
    conflict.
16. **Sidebar: 17 guides in one flat list.** Grouping (Start, Learn, Run,
    Build, Security) would help scanning. **Open**: also `astro.config.mjs`,
    and `feat/site-ecosystem-roadmap` is likely adding a page there.
17. **Emblem overlaps the live chip at 360 px** in the hero (the 3D core is
    pinned behind the copy on phones). Cosmetic. **Open**.

### Checked, nothing to fix

- **"First / only / unique"**: no novelty claim in `home.mdx`, `authored/`,
  components or pages; every "only" is a restriction ("written only if both
  signatures check out"). `cargo xtask claims-check` result is in the PR.
- **Alt text**: every `<img>` in components and pages has `alt` (decorative
  ones `alt=""` with `aria-hidden`).
- **Focus rings**: a global `:focus-visible` rule in `maya.css`; new
  components rely on it and add none that hide it.
- **Reduced motion**: global rule in `maya.css`; every new transition is
  also switched off locally.
- **Header backdrop-filter**: none on the header (brand rule); the new code
  adds none.
- **Images**: the emblem reaches pages through `astro:assets` (resized
  PNG); the 300 KB `public/brand/emblem.png` is not referenced by any page.
- **CSP**: the new components use processed `<script>` modules, which Astro
  hashes; no new entry in `security.csp.scriptDirective.hashes`.
  `check-csp.mjs` result in "Measured".
