Thank you for helping. Your computer becomes one of the machines that keep
the Maya2C test network running. Setting it up takes about five minutes, and you can
remove everything at any time.

:::note[Before you start]
- A computer that **stays on and plugged in**. A laptop works if you leave it on charge.
- An internet connection. No router settings are needed.
- Test coins have **no value**. Helping earns credit in the validator list, not money.
:::

Pick your computer once. Every section of this page then follows that choice.

## 1. Install

Choose your computer, its version, and how you want to install. The steps
below change to match, and every command has a **Copy** button. Tick **Done**
as you go, or switch on **One step at a time** to be walked through.

<InstallPicker guide="join" />

## 2. Check it is working

The first time, the node downloads the chain. **That can take up to an hour.** You don't need to do anything while it runs; the computer can be used normally.

<Tabs syncKey="os">
<TabItem label="Windows" icon="seti:windows">

Click **Start › Maya2C › Maya2C Status**.

</TabItem>
<TabItem label="Mac" icon="apple">

In Terminal, type `maya2c-validator status` and press **Return**.

</TabItem>
<TabItem label="Linux" icon="linux">

```bash
maya2c-validator status
```

</TabItem>
</Tabs>

| You see | It means |
|---|---|
| **the node is running** | Installed and running |
| **catching up: block 501,615 of 507,191** | Still downloading. Check again later |
| **in sync: block 507,191** | Done. Your node is following the network |
| **validating** | You are a validator (step 3) |
| **the node is not running** | See [Fix a problem](#fix-a-problem) |

## 3. Become a validator

A node that follows the chain already helps. A **validator** also votes on
every block. For now, Eric approves each validator by hand.

<Steps>

1. Make your application:

   <Tabs syncKey="os">
   <TabItem label="Windows" icon="seti:windows">
   **Start › Maya2C › Maya2C Become a validator**. It asks you to choose a
   wallet password, then opens your application in Notepad. The file is
   saved on your **Desktop** as `maya2c-application.txt`.
   </TabItem>
   <TabItem label="Mac" icon="apple">
   In Terminal: `maya2c-validator apply`. Choose a wallet password. Finder
   opens with `maya2c-application.txt` in your home folder.
   </TabItem>
   <TabItem label="Linux" icon="linux">
   `maya2c-validator apply`. Choose a wallet password. The application is
   saved as `~/maya2c-application.txt`.
   </TabItem>
   </Tabs>

2. **Write the wallet password down.** Nobody can recover it, not even Eric.

3. Send `maya2c-application.txt` to Eric any way you like: chat, email or the
   [application form](https://github.com/EricWijesinghe/Maya2C/issues/new?template=validator-application.yml).
   It holds only public information. **Never send** `validator.key` or `wallet.key`.

4. When Eric approves you, you get a **bond amount**. Register with it:

   <Tabs syncKey="os">
   <TabItem label="Windows" icon="seti:windows">
   Click **Start**, type **PowerShell**, and press **Enter**. Then run, with Eric's number:

   ```powershell
   & 'C:\Program Files\Maya2C\maya2c-validator.ps1' -Register 1000000000
   ```
   </TabItem>
   <TabItem label="Mac" icon="apple">
   ```bash
   maya2c-validator register 1000000000
   ```
   </TabItem>
   <TabItem label="Linux" icon="linux">
   ```bash
   maya2c-validator register 1000000000
   ```
   </TabItem>
   </Tabs>

5. Within about an hour, **status** shows **validating**.

</Steps>

:::caution[Your keys]
Run each validator key on **one** computer only. The same key on two
computers counts as double voting, and the network punishes it. Keep the
computer on: a validator that is often offline loses part of its bond.
:::

## Where your files are

<Tabs syncKey="os">
<TabItem label="Windows" icon="seti:windows">

| What | Where |
|---|---|
| Program | `C:\Program Files\Maya2C\` |
| Keys (secret) | `C:\ProgramData\Maya2C\validator.key`, `wallet.key` |
| Chain data | `C:\ProgramData\Maya2C\v0\` |
| Log | `C:\ProgramData\Maya2C\logs\node.log` |
| Background task | Task Scheduler › **Maya2C Validator** |

</TabItem>
<TabItem label="Mac" icon="apple">

| What | Where |
|---|---|
| Program | `/usr/local/bin/maya2c-node` |
| Keys (secret) | `/Library/Application Support/Maya2C/validator.key`, `wallet.key` |
| Chain data | `/Library/Application Support/Maya2C/data/` |
| Log | `/Library/Logs/Maya2C/node.log` (also in the **Console** app) |
| Background service | `/Library/LaunchDaemons/dev.maya2c.node.plist` |

</TabItem>
<TabItem label="Linux" icon="linux">

| What | Where |
|---|---|
| Program | `/usr/local/bin/maya2c-node` |
| Keys (secret) | `/var/lib/maya2c/validator.key`, `wallet.key` |
| Chain data | `/var/lib/maya2c/data/` |
| Log | `journalctl -u maya2c-node` |
| Background service | `maya2c-node.service` (systemd) |

</TabItem>
</Tabs>

## Fix a problem

<Tabs syncKey="os">
<TabItem label="Windows" icon="seti:windows">

| Problem | Fix |
|---|---|
| **"running scripts is disabled on this system"** | Use the exact line from step 1; it handles this. If you downloaded the file yourself, right-click it › **Run with PowerShell** |
| Nothing happens after clicking **Yes** | Look for a second PowerShell window behind the first |
| **the node is not running** | Restart the PC. Still not running? Open **Start › Maya2C › Maya2C Logs** and send Eric the last lines |
| Stuck on **catching up** for over an hour | Check the internet connection, then restart the PC |
| Antivirus removed `maya2c-node.exe` | Allow it in the antivirus, then **Start › Maya2C › Maya2C Update** |

</TabItem>
<TabItem label="Mac" icon="apple">

| Problem | Fix |
|---|---|
| **"there is no Maya2C build for this Mac yet"** | Older Intel Macs get their build with the next release; tell Eric |
| **command not found: maya2c-validator** | Close Terminal, open it again, and retry. Still missing? Run the install line again |
| **the node is not running** | `maya2c-validator restart`. Still not running? `maya2c-validator logs` and send Eric the last lines |
| Mac asks to **allow incoming connections** for maya2c-node | Click **Allow** |
| Status stops updating overnight | The Mac slept: see **Keep the Mac awake** in step 1 |

</TabItem>
<TabItem label="Linux" icon="linux">

| Problem | Fix |
|---|---|
| **needs curl** | `sudo apt install curl` (Debian/Ubuntu) or your distribution's equivalent |
| **the node is not running** | `maya2c-validator restart`, then `maya2c-validator logs` |
| **no systemd** | The installer prints the command to start the node yourself |

</TabItem>
</Tabs>

Still stuck? Send Eric the output of **status** and the last lines of the **log**. Never send a `.key` file.

## Update or remove

<Tabs syncKey="os">
<TabItem label="Windows" icon="seti:windows">

- **Update:** **Start › Maya2C › Maya2C Update**
- **Remove:** **Start › Maya2C › Uninstall Maya2C**. Your keys are kept in `C:\ProgramData\Maya2C`; delete that folder only if you will never validate again.

</TabItem>
<TabItem label="Mac" icon="apple">

- **Update:** `maya2c-validator update`
- **Remove:** `maya2c-validator uninstall`. Your keys are kept in `/Library/Application Support/Maya2C`.

</TabItem>
<TabItem label="Linux" icon="linux">

- **Update:** `maya2c-validator update`
- **Remove:** `maya2c-validator uninstall`. Your keys are kept in `/var/lib/maya2c`.

</TabItem>
</Tabs>

Running a server or want every flag explained? See [Run a validator](/guides/validators/), the full technical guide.
