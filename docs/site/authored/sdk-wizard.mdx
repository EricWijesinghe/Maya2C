| Language | Package | Published? | Talks to | Signs with |

| Rust | `maya2c-sdk` (`sdks/rust`) | No: git dependency | gateway REST `/v1` | `l1-wallet` |
| TypeScript | `maya2c.js` (`sdks/sdk-js`) | No: build from source | gateway REST `/v1` | `l1-wallet` |

Registry state was checked on 2026-11-13: npm, PyPI and crates.io answered 404
for the three unpublished names; `proxy.golang.org` resolved the Go module. CI
re-checks every install line in the SDK READMEs and on this page
(`.github/workflows/sdks.yml`), so a line that stops resolving fails a build
rather than a reader.

Every SDK leaves signing to `l1-wallet`, the Rust wallet shipped with the node,
so no second implementation of the hybrid ML-DSA-65 + SLH-DSA signature or the
wire format exists to disagree with the chain. [Wallet
integration](/guides/wallet/) says why.

## 1. A chain to talk to

From a clone of the repository, with Rust installed (the
[quickstart](/guides/quickstart/) sets both up per OS):

```sh
cargo xtask kit up
```

It builds `l1-wallet` and the node into `target/debug/`, starts four
validators (node 0's JSON-RPC on `127.0.0.1:32000`) and a gateway on
`127.0.0.1:8080`, and funds a wallet at `target/up/wallet.key` with the devnet
password `devnet-only-password`. Run the programs below from the repository
root, so those relative paths resolve.

`src/main.rs`, then `cargo run` in the same terminal:

```rust
use std::time::Duration;

fn main() -> Result<(), maya2c_sdk::Error> {
    let client = maya2c_sdk::Client::new("http://127.0.0.1:8080")?;
    let raw = std::env::var("RAW_TX").unwrap_or_default();
    let hash = client.send_raw_transaction(&raw)?;
    let height = client.wait_for_transaction(&hash, Duration::from_secs(60))?;
    println!("{hash} is in block {height}");
    let balance = client.balance("7777777777777777777777777777777777777777777777777777777777777777")?;
    println!("recipient: {} units", balance.balance);
    Ok(())
}
```

Checked by CI: the client's mock-gateway tests. Not checked: this program
(`cargo xtask sdk-e2e` has no Rust lane). [README](https://github.com/EricWijesinghe/Maya2C/blob/master/sdks/rust/README.md)

Sign the transfer with `l1-wallet` exactly as in the Rust tab (it sets
`RAW_TX`), then `hello.mjs`, run with `node hello.mjs`:

```js
import { GatewayError, MayaClient } from "maya2c.js";

const client = new MayaClient("http://127.0.0.1:8080");
try {
  const { hash } = await client.sendRawTransaction(process.env.RAW_TX ?? "");
  console.log("accepted into the mempool:", hash);
  const { balance } = await client.getBalance("7777777777777777777777777777777777777777777777777777777777777777");
  console.log("recipient:", balance); // a decimal string: amounts are 256-bit
} catch (e) {
  if (e instanceof GatewayError) console.error(e.status, e.message);
  else throw e;
}
```

Acceptance is acceptance into a mempool; poll the balance until it shows.
Checked: `cargo xtask sdk-e2e --lang ts` runs this flow (Rust-signed,
submitted from TypeScript, seen finalized) when run locally; nightly CI does
not run the TypeScript lane. [README](https://github.com/EricWijesinghe/Maya2C/blob/master/sdks/sdk-js/README.md)

`hello.py` (the SDK calls `l1-wallet` itself):

```python
import os, sys
from maya2c_sdk import Client, Wallet

client = Client("http://127.0.0.1:32000")
genesis = client.call("get_chain_info")["genesis"]
l1_wallet = "target/debug/l1-wallet" + (".exe" if sys.platform == "win32" else "")
wallet = Wallet(l1_wallet, "target/up/wallet.key", os.environ["L1_WALLET_PASSWORD"], client, genesis=genesis)

recipient = "7777777777777777777777777777777777777777777777777777777777777777"
print("txid:", wallet.transfer(recipient, 1_000))
client.wait_until(lambda: client.balance(recipient) >= 1_000, timeout=60)
print("recipient:", client.balance(recipient))
```

Checked by CI: the unit tests on every change, and nightly
`cargo xtask sdk-e2e --lang python`, which signs and submits a transfer with
`Wallet.transfer` against a devnet. [README](https://github.com/EricWijesinghe/Maya2C/blob/master/sdks/python/README.md)

`main.go`:

```go
package main

import (
	"fmt"
	"log"
	"math/big"
	"os"

	maya2c "maya2c.dev/sdk"
)

func main() {
	client := maya2c.NewClient("http://127.0.0.1:32000")
	var info struct{ Genesis string }
	if err := client.Call("get_chain_info", nil, &info); err != nil {
		log.Fatal(err)
	}
	wallet := maya2c.NewWallet(os.Getenv("L1_WALLET"), os.Getenv("MAYA_KEYSTORE"),
		os.Getenv("L1_WALLET_PASSWORD"), client)
	wallet.Genesis = info.Genesis
	txid, err := wallet.Transfer("7777777777777777777777777777777777777777777777777777777777777777", big.NewInt(1_000))
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("txid:", txid)
}
```

`L1_WALLET` and `MAYA_KEYSTORE` are the names the SDK's own live test reads.
Checked by CI: `go test ./...` on every change, nightly
`cargo xtask sdk-e2e --lang go` (a transfer through `Wallet.Transfer`), and the
`go get` line above against `proxy.golang.org`. [README](https://github.com/EricWijesinghe/Maya2C/blob/master/sdks/go/README.md)
