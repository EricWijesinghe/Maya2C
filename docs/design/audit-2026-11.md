# UI audit, November 2026 (Forged Light 2, job U0)

Scope: the five user-facing surfaces, screenshotted at 390 px and 1440 px in
dark and light where the surface has a light theme, scored on eight
criteria, with a concrete issue and a fix per cell. The direction that follows
from it is in [forged-light-2.md](forged-light-2.md). Nothing in this document
changes production code.

How it was produced (2026-11-12, worktree at `016ba40f`, plus PRs #462, #463,
#467, #474 merged into a scratch branch for the pages they add):

```
docs/site: npm ci && npm run build        -> 93 pages (master), 95 pages (with the four PRs)
node serve.mjs dist 4399 / 4398           -> local static server
node shot.mjs ... (playwright-core 1.56.1, Chromium 1254, SwiftShader GL)
node contrast.mjs                         -> WCAG 2.x ratios of every token pair below
```

Screenshots: [shots/](shots/) (first screen only, to keep the repository
small; the full-page captures are in the session scratchpad). The explorer
could not be screenshotted: `https://explorer.maya2c.dev/` answered HTTP 530
during the audit and the binary needs a cargo slot, so it is reviewed from
`apps/explorer/src/ui.rs` and `apps/explorer/assets/hud.css`. The wallet is
reviewed from `apps/wallet-gui/ui/styles.css` and `src/screens.rs` (a trunk
build invokes rustc). The chat was screenshotted with its welcome and
conversation views unhidden by script and three sample messages inserted; the
Hub shows its own built-in preview data.

Scores are 1 (blocks the "professional" goal) to 5 (nothing to do).

## 8. Top ten issues, ranked by what a visitor notices first

1. Website: no site navigation between 800 and 1151 px (`Header.astro:91`).
2. Chat: unusable at phone width, conversation clipped to a 70 px strip (`chat-gui/ui/style.css:95`).
3. Website hero: three equal CTAs, the live chip opens on `offline`, 300 px of empty first screen at 1440 (`Hero3D.astro:21-29,160`).
4. Wallet confirm: the clear-sign sentence has no style rule and the seven key/value rows weigh the same; two sequential primary buttons (`screens.rs:915-969`, no `.description` in `styles.css`).
5. Explorer: three overlapping style layers (`tokens.css`, `ui.rs` twice, `hud.css`); the Light toggle produces dark-on-dark; Inter is named but never loaded (`hud.css:22-31`, `ui.rs:141,692`).
6. Off-palette colour on the website: hue-wheel stack diagram, Tailwind cyan/violet/pink in the health constellation, violet counters (`StackDiagram.astro:40-52`, `HealthConstellation.astro:48,281`).
7. Health page: `gateway unreachable` set as the 56 px hero value; timeline axis at ~1.4:1 (`LaunchStatus`, `NetworkStatus`).
8. Four token vocabularies for one palette, ~580 colour literals; five radius scales; five primary-button styles (§7).
9. Motion never rests: infinite heading sweeps and dividers on every page, explorer scan line and spinning arcs, hero orbit, scroll-driven reveals that leave content invisible (`maya-living.css:89-131`, `hud.css:41-75`, `QuantumFacts.astro:105`).
10. Personal links in product chrome: "Built by Eric" in the primary nav, a personal email plus Facebook/Instagram/LinkedIn in every footer (`Header.astro:21`, `Footer.astro:26,38-70`).

## 9. What is already right and must stay

- The emblem-derived palette: teal, bronze, steel, abyss. Every surface already uses the same nine values; only the names and the extras differ.
- Manrope display + Inter body + JetBrains Mono, self-hosted (Hub and Wallet show how; the site uses `@fontsource-variable`).
- "Maya2C" as one word in every wordmark.
- Real numbers only; `—` for a missing value, on every surface (verified in `Hero3D`, `StatBand`, Hub tiles, `NetworkStatus`, stats page).
- Graphics over text: the 3D hero, the orb rows, the transaction journey, the ecosystem map, the gauge, the sent-tick animation.
- `prefers-reduced-motion` honoured on every surface.
- The Hub's bottom tab bar on phones and the wallet's 34 rem single column.
- The #474 design-explorer card, donut and filter chips.
