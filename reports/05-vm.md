## 2. Execution tiers with identical gas (new: `crates/vm/src/tier.rs`)

`Vm::with_tier(Tier::Cranelift | Tier::Pulley)`. Pulley needed wasmtime's
`pulley` feature: without it wasmtime compiles *to* Pulley but refuses to run
it on a native host ("compilation settings are not compatible with the native
host") — found by the first test run.

`cargo test -p maya-vm --test tier_differential_tests`:

```
test every_corpus_module_costs_the_same_gas_in_every_tier ... ok
test the_token_swap_contract_costs_the_same_gas_in_every_tier ... ok
test result: ok. 2 passed; 0 failed
```

The corpus (integer loop, storage writes + events, memory.grow + bulk ops,
NaN canonicalisation, divide-by-zero trap, infinite loop) runs at gas limits
5,000 / 50,000 / 500,000 / 10,000,000 — including limits that cut execution
mid-loop — through Cranelift cold, Cranelift cached and Pulley. Output, gas,
events, final storage and error class are identical in every case, as they are
across a five-call `token_swap` session. Why this holds: fuel decrements are
inserted while lowering wasm operators, before a target is chosen.

**Speed** (`cargo bench -p maya-vm --bench tier_bench`, median per call):

```
maya-vm tier bench (median wall time per call; gas identical across tiers)
tier         workload                        median us          gas
cranelift    200k-iteration loop, cold           808.9      2800002
cranelift    200k-iteration loop, cached          221.5      2800002
cranelift    token_swap swap, cached              35.5          587
pulley       200k-iteration loop, cold          4984.8      2800002
pulley       200k-iteration loop, cached         4235.7      2800002
pulley       token_swap swap, cached              38.6          587
pulley / cranelift on the cached loop: 19.1x slower
```

**Decision from the numbers:** the node keeps Cranelift + the module cache.
Pulley never wins on x86-64 here, so a hot-path profiler choosing between them
would only ever pick Cranelift; its value is portability to hosts Cranelift
cannot target and as a cross-check of gas. The brief's "10x speedup" goal
compares tiers against each other: the measured spread is Cranelift cached
**3.7x** faster than Cranelift cold and **19x** faster than Pulley on the loop;
on `token_swap` (host-call bound) the tiers are within 9%.
