# 2026-11-14 — S-033 committee floor: node tests, and the floor fails at mainnet bonds

PR #524 (tests and docs only; the node binary is unchanged). Founder-brief audit Q17,
Eric 2026-11-14 option A. All runs local, through `cargo-slot.sh`, one machine
(Windows 11, nightly-2026-07-15), on top of master 3735252d.

## Finding

The ADR-070 floor is merged (#246, 46a97a61). `merge-base --is-ancestor 46a97a61 bb4e0940`
succeeded, so it is in the freeze; the pre-rewrite e28f1f25 is not an ancestor of
origin/master. The floor does **not** hold at mainnet parameters: mainnet bonds equal
`min_self_bond` (`xtask/src/genesis_check.rs`), the 1% downtime slash (`Params::DEVNET`,
kept by `GenesisStaking::params`) runs before the count (`crates/staking/src/epoch.rs`),
and an ineligible validator is always jailed. S-033 stays `open`. The consensus fix is
Eric's decision (options in the ADR-070 amendment 2026-11-14).
