## Findings reported, not worked around (Standing Order 9)

1. **"Anyone can start mining" contradicts ADR-016.** DAG-BFT is the only
   production consensus; proof of work is devnet-only and refused by the
   production build. The node's miner builds empty blocks
   (`bins/maya2c-node/src/main.rs:544`), and there is no block reward:
   emission is nil, the base fee burns, and validators are paid from tips
   (ADR-029).
2. **No LICENSE file.** The SDKs declare Apache-2.0 and the Rust crates declare
   nothing. Without a license, organisations have no right to use the code.
3. **The cryptography has had no independent audit**, and it uses
   `slh-dsa =0.2.0-rc.5` (a release candidate). The guides say "evaluation
   and testnet use".
4. **Hybrid signing is only available inside the node crate**, which links
   RocksDB. A standalone signing crate would be the clean library for
   organisations; it is a consensus-path refactor needing review.
5. `infra/deploy/systemd/maya2c-miner.service` runs `miner --rpc`, a flag
   `maya2c-miner` does not have. Left alone: proof of work is devnet-only.
